## Method and status

Sanskrit candidates were read directly from original PNG pixels and lossless/enlarged crops. Formal Kannada meanings were prepared verse by verse. No OCR, Tesseract, Gemma, paid transcription, or alternate-edition text was used. Separate Kannada-script Sanskrit transliteration is provided as a script conversion of the candidate Sanskrit; it is not independently accepted text.

All accepted_sanskrit and accepted_kannada fields remain null. Original source files and canonical/book/publication materials were not changed. Source edition identity remains unverified.

Each main record contains source image SHA-256, original image dimensions, conservative pixel coordinates, and exact verse coverage. Bounding boxes are enclosing printed-line bands and may include adjacent text. Separate fragments document cross-page splits. Exact source spellings, anomalous forms, names, speakers, doctrine and negation are retained or explicitly flagged rather than silently normalized.
